# Archive

Эта папка хранит исторический код и snapshots, которые больше не участвуют в runtime, но нужны для восстановления контекста и отката решений.

- `rejected-redesigns/` — P20–P22: крупный редизайн, от которого команда отказалась. Сохраняется только как история.
- `legacy-snapshots/` — полные старые состояния, случайно/временно оставшиеся рядом с рабочим сайтом.
- `maintenance/` — старые cleanup/instruction notes.
- `legacy-tools/` — инструменты, относящиеся к старым миграциям.

Не подключать файлы из `archive/` к публичному сайту без отдельного согласованного решения.
