# Документация проекта

## Текущее состояние
- `current/PROJECT-STATE.md` — каноническая карта актуального runtime и backend.

## Релизы
- `releases/p-series/` — P14–P22, включая QA и UPDATE-документы.
- `releases/revival/` — REVIVAL R1–R6, UPDATE и QA рядом в одной папке.

P20–P22 сохранены как история отвергнутого большого редизайна. Их код находится в `/archive/rejected-redesigns/` и не должен использоваться как актуальный UI baseline.

## Backend
- `database/migrations/` — исторические миграционные заметки.
- `database/supabase/` — SQL/RPC материалы и применённые/планируемые изменения Supabase.

## Администрирование
- `admin/` — setup/roadmap-документы существующей старой админки.

## Прочее
- `history/` — вспомогательные исторические документы, не являющиеся текущими требованиями.

Правило: для каждого нового релиза сохранять минимум `UPDATE` + `QA`; если требуется изменение БД — отдельный SQL/migration document.
