## Рекомендуемый способ (Windows)

1. Сделай локальную копию/clone текущего GitHub-репозитория.
2. Распакуй содержимое P10 **в корень репозитория** с заменой `index.html`.
3. Открой PowerShell в корне проекта и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\migrate-p10.ps1
```

4. Убедись, что скрипт завершился строкой `MIGRATION OK`.
5. Проверь `git status` / GitHub Desktop: должны быть в основном renames + новый JS.
6. Commit + Push.

## Важно

Если скрипт сообщает, что отсутствует `trailer-preview.jpg`, не пушь миграцию до исправления: новый `index.html` ждёт `assets/images/signal/signal-preview.jpg`.

## Отзывы v2

Supabase-часть уже обновлена в проекте. Новый JS:

- не зависит от CDN `supabase-js`;
- не создаёт anonymous user при обычном просмотре страницы;
- публичные отзывы/статистика загружаются независимо от Auth;
- сетевые запросы имеют timeout вместо бесконечного ожидания;
- ник и аватар до первой публикации меняются локально мгновенно;
- после создания профиля изменения идут через атомарный RPC и возвращают фактическое состояние из БД;
- отзыв сохраняется атомарно через `save_my_review`, без гонок `upsert/select`.
