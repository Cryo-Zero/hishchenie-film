# ХИЩЕНИЕ / THEFT — официальный сайт

Статический официальный сайт фильма «ХИЩЕНИЕ / THEFT».

## Структура

```text
/
├─ index.html
├─ assets/
│  ├─ images/
│  │  ├─ archive/     # постеры и визуальные материалы
│  │  └─ signal/      # изображения трейлера / UI
│  └─ video/
│     └─ signal/      # трейлер
├─ js/
│  └─ public-response.js  # анонимные профили, оценки и отзывы
├─ docs/
│  ├─ migration/
│  └─ supabase/
└─ tools/
```

## Принципы проекта

- RU / EN интерфейс.
- Анонимные отзывы без email, телефона, пароля и соцсетей.
- Оценка 0–10; 7–10 считается положительной для «Свежести».
- Один отзыв на один анонимный профиль; свой отзыв можно изменять и удалять.
- Оригинальные материалы фильма не переводятся автоматически.

## Supabase

Клиентская часть использует только публичные ключи и RLS. Секретные/service-role ключи в репозитории запрещены.
